Navigation

Diretrizes de navegação baseadas em Carbon Design System e Material Design para criar interfaces intuitivas e acessíveis.

Quando Usar Cada Padrão

Padrão Quando Usar Evite Se
Top Menu (Horizontal) 3-7 itens de navegação de mesmo nível hierárquico Mais de 8 itens ou hierarquia profunda
Side Menu (Lateral) 8+ itens, navegação hierárquica (submenus) Poucos itens de navegação simples
Mega Menu Muitas categorias com subcategorias (e-commerce, portais) Aplicações focadas em uma tarefa
Burger Menu (☰) Mobile/tablets (< 768px), espaço limitado Desktop com espaço disponível
Tabs 3-5 seções dentro de uma mesma página Navegação entre páginas diferentes

Wireframes dos Padrões

1. Top Menu (Horizontal)

Uso: Sites institucionais, landing pages. Navegação sempre visível.
Máximo: 7 itens (regra de Miller)

2. Side Menu (Lateral)

Uso: Aplicações web, dashboards, sistemas.
Permite: Hierarquia (submenus expansíveis)

3. Mega Menu

Uso: E-commerce, portais com muitas categorias.
Mostra: Múltiplas colunas de subcategorias

4. Burger Menu (Mobile)

Uso: Obrigatório em mobile (< 768px).
Comportamento: Abre drawer lateral, overlay escurece fundo

Boas Práticas (Carbon + Material Design)

✓ Sempre faça
  • Indique visualmente a página ativa (cor, borda, negrito)
  • Mantenha menu consistente em todas as páginas
  • Use ícones + texto (mais claro que só ícones)
  • Máximo de 7 itens no menu principal (regra de Miller)
  • Forneça feedback visual (hover, focus, active)
  • Torne navegação acessível via teclado (Tab, Enter)
✗ Evite
  • Menus muito profundos (máximo 3 níveis)
  • Esconder navegação crítica (principal sempre visível)
  • Usar apenas ícones sem labels (ambíguo)
  • Dropdowns complexos com delay para abrir
  • Mais de 2 barras de navegação (confuso)
  • Animações longas (> 300ms) ao abrir menus

Breakpoints Responsivos

Dispositivo Largura Padrão Recomendado
Mobile < 768px Burger Menu (☰)
Tablet 768px - 1024px Burger ou Top Menu (depende do contexto)
Desktop > 1024px Top Menu ou Side Menu (conforme complexidade)
Princípio fundamental (Nielsen Norman Group)
O usuário deve sempre saber: "Onde estou? De onde vim? Para onde posso ir?"
