Design System / VIVIX / Fundamentos

Fundamentos

Elementos fundamentais da identidade visual corporativa: logotipo, paleta de cores, tipografia e sistema de espaçamento.

Diretrizes obrigatórias para geração de materiais

Ao gerar apresentações, documentos ou PDFs a partir desta página:

• Grafismos: O grafismo institucional são polígonos angulares derivados do logotipo Vivix (arquivos: assets/vivix-grafismo-shapes.svg, vivix-grafismo-gradient.svg, vivix-grafismo-lines.svg). Aplicar como shapes sobrepostos com gradiente/opacidade em tons teal/verde ou com hachura amarela. Nunca usar formas sem relação com o logotipo. Nunca usar círculos, ondas ou formas genéricas com opacidade — isso não faz parte da identidade visual.

• Tipografia: Usar Arial para slides, documentos e PDFs. A fonte Inter é exclusiva para ambientes digitais interativos (Web, SAP BTP, Mendix).

• Fundos: Apenas branco, cinza claro (var(--color-neutral-light)) e escuro (var(--color-neutral-dark)). Fundo escuro reservado para capa/encerramento/transição.

• Ícones: Uma única cor de destaque por material. Não alternar cores aleatoriamente entre cards.

• Rodapé: Nome da apresentação + número da página em todo slide interno (exceto capa).

Consulte a seção Composição para detalhes completos, mockups de referência e checklist de validação.

Sistema de Logos VIVIX

O sistema de identidade visual VIVIX é organizado em 3 níveis hierárquicos: Logos Principais (hierarquia alta - marca institucional), Facilita (hierarquia média - produtos digitais) e Soluções Internas (hierarquia baixa - ferramentas operacionais).

Respeite a hierarquia: Use logos principais para comunicação institucional, Facilita para produtos, e soluções internas apenas para ferramentas operacionais

Information
Uso: Mensagens informativas, tooltips, ajuda contextual
Interactive

Diretrizes de Aplicação (quando usar cada espaçamento)

1. Espaçamento entre componentes

Contexto Token Exemplo de uso

Itens de lista --spacing-04 (12px) Entre itens de menu, lista de links
Elementos muito próximos --spacing-03 (8px) Entre ícone e texto, badge e label

2. Padding interno de componentes

Componente Token Observação
Containers principais --spacing-09 (48px) Desktop. Mobile: --spacing-05
Cards --spacing-06 (24px) Padding uniforme em todos os lados
Botões --spacing-04 horizontal
--spacing-03 vertical		 12px left/right, 8px top/bottom

Alerts / Notifications --spacing-05 (16px) Padding confortável para leitura
Modais / Dialogs --spacing-07 (32px) Header e body. Footer: --spacing-06

3. Margens de elementos tipográficos

5. Hierarquia de espaçamento (princípio)

Regra fundamental: Quanto mais importante ou separado conceitualmente, maior o espaçamento.

Nível Espaçamento Exemplo
Seções diferentes 64px Header → Hero → Conteúdo → Footer
Blocos da mesma seção 40px Entre grupo de cards e sidebar

Elementos do mesmo componente 16px Título e descrição dentro de um card
Itens muito próximos 8-12px Ícone ao lado de texto, items de menu

Sistema de breakpoints para design responsivo, baseado no Carbon Design System. Grid fluido de 16 colunas que se adapta a diferentes tamanhos de tela.

Small
320px - 671px
Mobile devices em modo portrait e landscape. Layout de coluna única com navegação simplificada.
Medium
672px - 1055px
Tablets e dispositivos híbridos. Layout com sidebar colapsável e grid de 2-3 colunas.
Large
1056px - 1311px
Desktop padrão. Layout completo com sidebar fixa, múltiplas colunas e navegação expandida.
X-Large
1312px - 1583px
Monitores wide. Layout otimizado com espaçamento ampliado e dashboards multi-coluna.
Max
1584px+
Ultra-wide displays e configurações multi-monitor. Conteúdo centrado com max-width de 1584px.
Exemplo de uso em CSS:
/* Mobile first approach */ .container { padding: 16px; } /* Tablet */ @media (min-width: 672px) { .container { padding: 24px; } } /* Desktop */ @media (min-width: 1056px) { .container { padding: 32px; max-width: 1584px; } }

Composição

Diretrizes de composição para materiais gerados fora do ambiente web — apresentações, documentos e PDFs. Os tokens de cor, tipografia e espaçamento acima definem os átomos; esta seção define como combiná-los em um layout completo, com base no Manual de Marca VIVIX. A tipografia Inter é reservada para ambientes digitais interativos (Web, SAP BTP, Mendix) — não deve ser usada em slides, documentos ou PDFs.

Grafismos e elementos gráficos

O grafismo deriva da desconstrução angular das formas do logotipo VIVIX, gerando ângulos diversos aplicados coloridos (cores principais), em degradê, ou transparentes sobrepostos a fotografias. Nunca usar formas fechadas genéricas sem relação com o desenho do logotipo. A cor amarela (var(--color-secondary-2)) é exclusiva para detalhes pontuais — seu uso predominante não é permitido pelo manual.

Aproximação do grafismo institucional — usar o arquivo vetorial oficial quando disponível
Nunca fazer
  • Círculos ou formas genéricas com opacidade que não derivem do símbolo da marca
  • Grafismo competindo visualmente com o logotipo ou a área de não-interferência
  • Grafismo como forma fechada/preenchida sem nenhum tipo de corte
  • Cores fora da paleta institucional aplicadas ao grafismo
Fundos padrão

Três fundos são permitidos para materiais institucionais. Não usar gradientes aleatórios, fotografias como fundo de texto corrido, ou cores fora desta lista.

Branco

Fundo padrão para conteúdo denso — slides de texto, corpo de documentos, tabelas. Máxima legibilidade.

Cinza claro

Para cards, seções de destaque dentro de um slide/página branca, ou alternância visual entre blocos de conteúdo.

Verde escuro Vivix

Reservado para capa, encerramento, ou slides de transição/divisor de seção. Não usar em slides de conteúdo denso (prejudica legibilidade de leitura longa).

Hierarquia tipográfica para documentos e slides

Fonte institucional (Prometo (títulos) + Open Sans (corpo)) para títulos e destaques. Fonte de apoio (Arial) como alternativa de sistema quando a institucional não estiver disponível — é a fonte recomendada para geração automática via IA, já que garante abertura correta em qualquer ambiente sem depender de licença instalada.

Apresentações (slides)

Estrutura de referência para geração de decks. Alternância de fundo deve ser controlada — não alternar por estética, apenas por função do slide.

Capa — fundo verde escuro vivix, logo topo-esquerda, título + subtítulo centro-esquerda, assinatura inferior em cor de destaque
Slide interno — fundo branco, cards cinza claro, uma única cor de destaque nos ícones, rodapé com numeração

Cards

Fundo var(--color-neutral-light), border-radius var(--radius-md) ou var(--radius-lg), espaçamento entre cards var(--spacing-05) a var(--spacing-06). Nunca usar sombra pesada — var(--elevation-01) no máximo.

Ícones / badges

Badge circular (var(--radius-full)), ícone branco sobre cor sólida. Verde escuro (var(--color-secondary-1)) preferencial; amarelo (var(--color-secondary-2)) apenas como detalhe pontual — nunca em ícones grandes ou predominantes. As cores UX/UI secundárias (lilás, roxo, azul) são exclusivas de interfaces digitais e não devem aparecer em slides institucionais ou documentos formais. Não alternar cores de ícone aleatoriamente entre cards do mesmo slide.

Rodapé e numeração

Nome da apresentação (esquerda) + numeração de página (direita), fonte Arial 8–9pt, cor var(--text-secondary). Ausente apenas na capa.

Documentos e PDF

Margens

Margem de página: 2,5–3,5cm (equivalente ao padrão de papel timbrado do manual). Área de respiro mínima ao redor do logotipo conforme regra de não-interferência.

Cabeçalho

Logotipo no canto superior esquerdo ou centralizado, altura entre 8–12mm. Nunca redimensionar abaixo da redução mínima definida no manual.

Rodapé

Numeração de página + nome do documento, fonte Arial 8pt, cor var(--text-secondary). Para documentos confidenciais, incluir marca d'água textual conforme padrão de material de expediente.

Checklist de validação
Fazer
  • Usar apenas as cores desta página (tokens de marca)
  • Uma cor de destaque por material — não misturar cores de ícone sem critério
  • Grafismo derivado do símbolo, sempre cortado
  • Fundo escuro só em capa/transição/encerramento
  • Arial para documentos, slides e PDF gerados por IA
  • Rodapé com numeração em todo material com mais de 1 página/slide
Não fazer
  • Formas genéricas (círculos com opacidade, ondas aleatórias) sem base no manual
  • Inter em slides, documentos ou PDF (reservada a Web/SAP BTP/Mendix)
  • Distorcer, inverter cores ou alterar a fonte do logotipo
  • Aplicar a marca sobre fundos que prejudiquem a leitura
  • Misturar fundos claros e escuros sem lógica de função do slide
