# Plataforma IA Industrial

Checklist interativo multi-fornecedor para decidir **Comprar / Construir / Híbrido** em uma plataforma de IA industrial.

## Pilares

1. Dados e camada de contexto
2. Desenvolvimento
3. Testes e avaliação
4. Implantação
5. Orquestração
6. Governança e controle
7. Aplicações e serviços
Síntese: inventário organizacional

## App web

- Produção: https://plataforma-ia-industrial.vercel.app
- Código: pasta `web/` neste repositório
- Aba **Nao**: exporta `avaliacoes.csv` e embute o chat em `http://localhost:5005`
